# 夏希と放課後

公開先: https://ibushimaru.github.io/monochrome-demo/

夏希の頭を直接タップすると、手の画像が1→2→1→2と切り替わり、顔の横に短い反応が出る非性的な操作デモです。連打・回数・好感度による制限はありません。手は最後のタップから1.2秒後に消えます。

ゲーム性は未実装。好感度ゲージは仮表示の0で固定し、以前の保存データは読み込みません。表情と短いセリフは操作確認用です。

手の画像は同じサイズで重ね、頭より上をCSSで表示します。タップ判定は絵と同じ相対座標を使い画面サイズに追従します。

ローカル: `python3 -m http.server 8765` を実行して `http://localhost:8765` を開きます。

画像は内蔵画像生成で制作。夏希の設定画を参照し、白黒アニメ調、同じ服装・構図の通常顔、笑顔、頭を撫でる手2コマを指定。保存先は assets/natsuki/。
