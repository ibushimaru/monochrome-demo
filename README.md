# 夏希と放課後

公開先: https://ibushimaru.github.io/monochrome-demo/

頭・左右の頬・左右の肩を直接タップする非性的な操作デモ。

- 頭: 撫でる手と短い反応。
- 頬: 人差し指でつつく。吹き出しは指に重ならない位置へ移動。
- 肩: 手で軽く叩き、「呼んだ？」などの反応。

連打・回数・好感度による制限はありません。部位ごとに2つの接触位置と短いセリフを交互に表示します。手は最後のタップから1.2秒で消えます。好感度は仮表示の0で固定です。

キャラは一枚の固定画像。アルファ透過の手だけを重ねるため、髪や顔の描画がタップでずれません。左右の判定と画像はキャラと共通の相対座標です。

ローカル: `python3 -m http.server 8765` を実行して `http://localhost:8765` を開きます。

## 素材

assets/natsuki/illustration-v2.png: 細部を減らした白黒イラスト。
assets/natsuki/hand-transparent-v2.png: 袖なしの手。
assets/natsuki/poke-transparent.png: 頬をつつく人差し指。

内蔵画像生成を使用。指の生成指定は「横向きに人差し指を伸ばした自然な右手、袖なし、簡潔な白黒線画、最小限の薄い影、背景は透過」。

## 手の簡略版

内蔵画像編集ツールで作成。使用素材: `assets/natsuki/hand-flat.png`（頭・肩）、`assets/natsuki/poke-flat.png`（頬）。

編集指示: 元のシルエット・ポーズ・向き・余白を維持し、参考画像のような薄いグレーのベタ塗りと細い輪郭線へ変更。指の境目以外の線、爪、関節のしわ、手の甲の筋、陰影、質感を除去。袖なし、透過背景。

## セリフの間

手は即座に反応し、セリフは550〜1000ms遅れて表示。表示を2.6〜4.2秒保ち、その後2〜3秒の沈黙を挟みます。連打で文面や表示時間を更新せず、実際に話した回数で部位別セリフを進めます。最後の操作から1.6秒以上経過した待機反応は破棄し、リセット時も待機中の反応を消します。音声の追加はありません。
