# 余白の部屋 — 2コマデモ

`index.html` をSafariやChromeで開くと遊べます。インストール、サーバー、ネット接続は不要です。

- イラスト、または「頭を撫でる」をクリックすると手が2コマで交互に切り替わります。
- 表情は3種類から選べます。
- 「最初に戻す」でコマ・回数・表情を初期化します。
- ボタンはキーボードのTabで選択し、EnterまたはSpaceでも操作できます。

成人の架空キャラクターを使った、非性的な操作確認用デモです。絵は独自の仮SVGイラストです。セーブ機能や販売用パッケージはまだありません。

## 構造

HTML・CSS・JavaScriptのみで作っています。ゲームエンジンや外部ライブラリは使用していません。

`index.html` 内のSVGを、体のベース、表情（`face-*`）、手の差分（`hand-0`・`hand-1`）に分けています。クリックで表示する差分を切り替え、途中の補間はしません。

今後描いた絵を使う場合も、この3層を同じキャンバスサイズと位置で揃えると置き換えやすくなります。
