# 夏希と放課後

白黒の会話シミュレーション試作。公開先: https://ibushimaru.github.io/monochrome-demo/

「話す」で吹き出しに質問が出て、二択で返答します。返事で好感度が増減し、表情が自動で変わります。好感度50以上で頭を撫でると2コマの演出が入り、連続で撫ですぎると嫌がります。「ひと休み」で会話や連続操作を区切れます。進行は端末のlocalStorageへ保存します。

普通の会話と頭を撫でる非性的なデモです。キャラクターは架空の成人です。

ローカル実行: このフォルダで `python3 -m http.server 8765` を実行し `http://localhost:8765` を開きます。

- index.html / style.css: 画面
- game.js: 会話・好感度のルール
- app.js: 表示・操作・保存
- assets/natsuki/: 内蔵画像生成で制作した通常・笑顔・撫でる2コマのPNG

生成指定: 夏希の設定画を参照し、白黒アニメ調、同じ衣装と構図を維持した成人女性の非性的な立ち絵。通常、笑顔、自然な手で頭を撫でる2コマへ展開。
