# 夏希と放課後

公開先: https://ibushimaru.github.io/monochrome-demo/

夏希の頭の部分を直接タップする、非性的な頭なでデモ。返答を選ぶ会話や行動ボタンはありません。顔の横に短い反応が出ます。

最初は警戒します。4秒ほど触らずに待つと反応が変わります。その後は間隔を空けて頭をタップすると好感度が上がり、表情も変わります。連打すると嫌がり、好感度が下がります。好感度と打ち解けた状態はlocalStorageに保存します。

手の2枚の画像は同じサイズで重ね、頭より上の部分だけCSSで表示することでキャラクターの表情と独立させています。頭の判定は絵と同じ相対座標を使い、画面サイズに追従します。

ローカル: `python3 -m http.server 8765` を実行して `http://localhost:8765` を開きます。

画像は内蔵画像生成で制作。夏希の設定画を参照し、白黒アニメ調、同じ服装・構図の通常顔、笑顔、頭を撫でる手2コマを指定しています。保存先は assets/natsuki/。
